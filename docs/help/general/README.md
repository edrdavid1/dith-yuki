# General workspace guide

Dither Yuki in **General** workspace is for dithering images for web, print, and
general graphics.

## Getting started

1. Open or create a document.
2. Add a dither (or other) effect from the Effect panel.
3. Export via File → Export Image, or use Batch Export for folders.

## Dithering

Choose an ordered or error-diffusion mode, adjust levels and pixel size, and
export. For tiling and seamless workflows, see the [Gamedev guide](../gamedev/README.md).

## Patterns and batch

Pattern Manager and Batch Export are available in every workspace.
